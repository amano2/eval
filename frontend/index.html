The 3-Level Evaluation Pyramid

Inspired by Hamel Husain's field guide: replace subjective vibes with layered, repeatable feedback loops that run at every stage of the software lifecycle.

LEVEL 1 Cheap • Fast • Every PR

Deterministic Assertions & CI Gates

Pure functions (case, output, trace) → Result. Evaluates structural validity, citation grounding, forbidden leaks, and schema conformance in milliseconds.

  • 12 Built-in assertions (no_pii, citations)
  • Dual-use as online runtime guards
  • CLI exit code: 0 pass, 1 gate fail, 2 err
Target Speed: < 3 min / 200 cases
LEVEL 2 Nightly • Pre-Minor

Human Review & Aligned LLM Judges

Frictionless human labeling using binary [G] Good / [B] Bad with mandatory critiques. Aligns LLM judges by reporting Precision & Recall against human ground truth.

  • Treats 'Bad' (defects) as positive class
  • Confusion matrix + Disagreement queue
  • Blind review mode to remove confirmation bias
Alignment Standard: ≥ 0.85 P&R (50+ labels)
LEVEL 3 Production • A/B Rollout

Online Experiments & Fine-Tuning Flywheel

A/B assignment framework for production traffic. Approved traces and corrected failure critiques automatically export to OpenAI/Anthropic fine-tuning datasets.

  • Deterministic hash-based cohort assignment
  • Export curated JSONL fine-tuning data
  • 100% confirmed bugs become permanent test cases
Production Overhead: < 5 ms / span (buffered)

Architecture & Fail-Safe Data Flow

Designed so that under no circumstances can an evaluation outage, database timeout, or tracing error interrupt the host application.

1

Non-Blocking Client SDK (Python & TypeScript) < 0.1ms overhead

Context managers with trace(...) and with span(...) write to an in-memory ring buffer. A background daemon thread flushes batches. If the server is offline, items are dropped and counted—never throwing an exception.

2

Ingestion Gateway & Dual-Redaction Engine SHA256 Idempotent

Ingestion at /api/ingest verifies API keys, ensures idempotency by external_id, strips API secrets and PII (credit cards, SSNs) client-side and server-side, and offloads payloads >64KB to storage.

3

Deterministic Assertion Engine & Runtime Guards Pure Functions

Modular assertions check output constraints. In production, guard("has_citation", output) performs an immediate 1-shot retry prompting the model with the exact failure critique before returning to the user.

4

Release Gate Policy & CI Enforcement Exit Code Gate

Enforces policies per scenario. evalkit gate --run-id latest evaluates pass rates and deltas against baseline. If any blocking gate fails, it terminates with exit code 1 to stop CI/CD deployment.

        docs = vector_db.query(query)
        s.set_output({"count": len(docs)})

    # 3. Track model inference span

        answer = llm.generate(query, docs)

    t.set_output(checked)
